# Patrimonio de Galois Legacy

35 sprites PNG individuales, con canal alfa, organizados por las diez localidades del juego. Son reinterpretaciones artísticas de monumentos y tradiciones reales, no reproducciones arquitectónicas exactas. El manifest.json indica identificadores, rutas y dimensiones originales.

Se recomienda renderizar con escalado nearest-neighbor (CSS: image-rendering: pixelated) y mantener la proporción de cada sprite.
